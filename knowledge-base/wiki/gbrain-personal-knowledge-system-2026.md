# GBrain个人知识系统：元元提示法与复利AI基础设施

**来源**: Garry Tan (YC CEO) X长文 & GitHub开源
**整理日期**: 2026-05-10
**核心价值**: 从一次性工作流到复利增长系统的构建方法论

## 🎯 核心框架

### 一、元元提示法（Meta-Meta-Prompting）

**三层结构**:
1. **Prompt** - 单次问题
2. **Meta-Prompt** - 提示工程，优化单个任务
3. **Meta-Meta-Prompt** - **把工作流程本身变成可积累的技能**

**核心循环**（Skillify）:
```
手工执行一次工作流
    ↓
运行Skillify元技能
    ↓
提取可复用模式
    ↓
生成技能文件（触发条件 + 边缘情况 + 测试）
    ↓
注册进路由表
    ↓
自动触发，执行效果比上一次更好
    ↓
发现新边缘情况
    ↓
更新技能
    ↓
重复循环
```

> **技能造技能**: 不是写一个更好的提示词，而是构建一个让每次工作的结果反哺下一次工作的系统。

**关键洞察**:
- 第一次做的东西可以很烂，这是重点
- 用它，读输出，当有什么不对的时候运行跨模型评估
- 六个月后会拥有任何聊天机器人都无法复制的东西
- **价值不在模型里，价值在于你已经教给系统的、关于你自己的生活、工作和判断的一切**

### 二、GBrain系统架构

**一句话概括**: 一个结构化的个人知识库，目前约100,000页

**三层结构**:
- **顶部**: 当前最佳理解（已编译的真相）
- **中部**: 只增不减的时间线
- **底部**: 原始数据侧边栏（会议记录、文章摘录、语音笔记）

**核心组件**:

1. **薄外壳（OpenClaw/Hermes Agent）**
   - 几千行路由逻辑
   - 接收消息，判断调用哪个技能，分发
   - **什么都不知道** - 不知道书、会议、创始人
   - 只负责路由："谁来了，该叫谁来处理"
   - **外壳可替换，技能和知识库不动**

2. **胖技能（100+个）**
   - 每个是独立的Markdown文件
   - 包含具体任务的详细指令
   - 书镜、会议备忘、实体传播、人物研究、多模态摄入
   - 每个技能只做一件事，做好它
   - 技能可组合，一个工作流调用多个技能

3. **大语言模型（引擎）**
   - 自己不是车，只是引擎
   - 不同任务用不同模型：
     - Opus 4.7 1M: 需要精确性的任务
     - GPT-5.5: 需要充分提取的任务
     - DeepSeek V4-Pro: 创意工作和第三视角
     - Llama (Groq): 需要速度的场景
   - **模型是最可替换的零件**

**工作流程示例**: 会议备忘技能（2分钟）
```
1. 大脑里的完整页面（人物时间线、当前状态、开放线索、得分）
2. 公开立场数据库（AGI时间线、研究优先级）
3. 传记摘要
4. 我的公开立场与对方交叉点和分歧点
5. 演示脚本（展示多跳推理能力）
→ 输出：完整的对话准备包
```

**知识库增长**:
- 每次会议 → 创建/更新人物页面 → 更新公司页面 → 交叉引用会议记录 → 检查是否见过 → 浮出上次谈了什么 → 提取申请数据 → 拉最新指标 → 匹配投资组合联系人
- 结果：下次见面前，完整上下文包已准备好

### 三、跨模型评估框架

**为什么需要评估？**

书镜1.0版本有3个事实错误:
- 说父母离婚了（实际没离）
- 说在香港长大（实际加拿大出生）
- 基础事实错误，对信任损害巨大

**三模型互相打分**:
- **Opus 4.7 1M**: 主攻事实精确性
- **GPT-5.5**: 负责上下文完整性
- **DeepSeek V4-Pro**: 检查是否太过泛泛

**机制**: 每次书镜生成后，必须通过跨模型评估，错误在输出前就被挡住。

**升级**:
- 检索逻辑升级到版本3
- 每个映射条目都附有引用来源（大脑哪一页、哪次会议、哪条笔记）
- **有据可查 vs 聊天机器人输出**: 前者可审计和改进，后者不能

### 四、技能组合与复利增长

**技能可组合**:
- 书镜技能调用大脑操作来存储
- 调用增强工具来加上下文
- 调用跨模型评估来保质量
- 调用PDF生成来输出
- **每个技能只负责一件事，组合成复杂工作流**
- **改进一个技能，所有依赖它的工作流自动变好**

**复利的本质**:
- 每一次会议都在增厚大脑
- 每读一本书，下一本书的上下文更丰富
- 每建一个技能，下一个工作流更快
- **系统今天是两个月前的10倍，两个月后会是今天的10倍**

> **未来属于那些建立了复利AI系统的个体，而不是使用企业拥有的中心化AI工具的个体。差别就是保存一本日记和拥有一个神经系统之间的差别。**

### 五、每天100+定时任务

GBrain的自动化运转:
- 社交媒体监控
- Slack/邮件/日历扫描
- 会议摄入自动运行
- 邮件分类每10分钟跑一次
- 知识图谱从每次对话中自我更新

**复合效果示例**:
创始人office hours见到某人 → 系统:
1. 创建/更新个人页面
2. 更新公司页面
3. 交叉引用会议记录
4. 检查是否见过（浮出上次谈的）
5. 提取申请数据
6. 拉出最新指标
7. 匹配投资组合或联系人中的相关问题
→ 下次见面前，完整上下文包已准备好

### 产品线1：个人知识大脑构建服务（PKB）

**客单价**: ¥30-80K（4-6周）
**6个月目标**: 15-25个客户，收入¥450-1,500K

**目标客户**: 知识工作者（创始人、投资人、顾问、研究者）
**核心需求**: 像Garry Tan一样建立持续运转的个人知识系统

**交付物**:
1. **知识库架构设计**（2周）
   - 三层结构（当前理解 / 时间线 / 原始数据）
   - 技能清单（30-50个核心技能）
   - 数据源接入（日历/邮件/会议/阅读）

2. **核心技能实现**（2-3周）
   - 会议备忘技能（2分钟准备）
   - 人物研究技能（一键生成人物页面）
   - 书镜技能（书籍映射个人经历）
   - 实体传播技能（会议后自动更新）
   - 邮件分类与摘要技能

3. **跨模型评估框架**（1周）
   - 三模型互评配置（事实精确性 / 上下文完整性 / 泛化检查）

   - 定时任务（10分钟跑一次邮件分类）

   - 知识图谱自我更新

**技术栈**:
- **外壳**: OpenClaw（路由逻辑）
- **技能**: Markdown文件 + Python实现
- **知识库**: Notion API 或 自建Graph DB
- **模型**: 多模型路由（Opus/GPT/DeepSeek）
- **存储**: S3/Cloudflare R2 + Postgres

**价格分层**:
- **基础版**: ¥30-50K（20个技能 + 核心流水线）
- **专业版**: ¥50-80K（50个技能 + 完整自动化）

### 产品线2：技能工厂（Skillify as a Service）

**客单价**: ¥20-40K/技能（或¥100K包月不限量）

**核心价值**: 让客户的工作流自动变成可复用技能

**服务模式**:
1. 客户描述一个重复性工作（"每周准备投资人更新"）
2. 我们先手工执行一次，记录完整步骤
3. 运行Skillify流程，提炼成技能文件
4. 注册进客户的路由系统，从此自动执行
5. 后续优化：客户使用中发现问题，我们迭代技能

**典型技能清单**（可销售）:
- 周报/月报自动生成（从日历、邮件、项目数据）
- 投资人更新准备（公司最新数据、行业新闻、个人亮点）
- 会议纪要自动整理 + 行动项提取
- 书籍阅读笔记生成（书镜简化版）
- 候选人研究（面试前快速生成人物页面）
- 市场动态监控（指定关键词，每日摘要）

**商业模式**:
- 按技能收费：¥20-40K/个（标准化技能）
- 订阅模式：¥100K/月（不限技能数量，适合高频率场景）
- 企业定制：¥200-500K（构建完整的企业技能库）

**护城河**:
- 技能之间的组合效应（一个技能改进，所有使用它的流程变好）
- 数据飞轮（客户使用越多，技能越精准）
- 迁移成本（一旦技能积累，不会轻易换供应商）

### 产品线3：跨模型评估框架实施

## ⚠️ 风险与挑战

### 风险1：市场认知门槛高

**问题**: GBrain系统太复杂，客户难以理解价值

**缓解**:
- **简化表达**: 不提100,000页，说"2分钟会议准备"
- **痛点导向**: "你每周花多少时间准备会议？2分钟够吗？"
- **POC先行**: 14天免费试用（核心技能：会议备忘 + 人物研究）
- **案例说话**: 用Garry Tan的423K浏览量 + YC CEO背书

### 风险2：实施复杂度

**问题**: 技能定制化需求多，难以规模化

**缓解**:
- **技能模板化**: 20个核心技能标准化，像乐高一样组合
- **配置化**: 大多数技能通过配置文件（非代码）调整
- **自助+专家**: 基础版本自助，高级版本专家实施
- **社区共享**: 建立技能市场，用户可以买卖/分享技能

### 风险3：数据隐私与安全

**问题**: 个人知识库包含敏感信息（会议记录、邮件）

**缓解**:
- **本地优先**: 默认部署在客户自己的云/本机
- **端到端加密**: 数据传输和存储都加密
- **权限控制**: 基于角色的访问控制（家人/助理/团队）
- **合规性**: GDPR/CCPA/个人信息保护法合规
