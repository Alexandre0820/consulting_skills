# 共享上下文图谱（Shared Context Graph）- AI智能体协作基础设施

## 核心概念

**定义**：结构化的、可查询的、会自我进化的智能体间共享知识网络，是下一代AI协作的基础设施。

**市场规模**：Foundation Capital认为是下一个**万亿美元级别**的平台机会。

## 技术架构：五个核心子图谱

### 1. 代码图谱（Code Graph）
- **功能**：函数、类、依赖关系、调用链管理
- **价值**：帮助智能体理解和导航代码库，识别改动影响范围

### 2. 决策图谱（Decision Graph）
- **功能**：记录架构决策理由、替代方案、权衡因素
- **价值**：完整的决策追溯，避免重复错误

### 3. 会话图谱（Conversation Graph）
- **功能**：操作记录、时间戳、变更摘要
- **价值**：完整的审计轨迹，精确追溯任何变更

### 4. 任务图谱（Task Graph）
- **功能**：任务分配、依赖关系、状态、优先级
- **价值**：协调层，避免重复工作

### 5. 代码仓库图谱（Repo Graph）
- **功能**：拉取请求、议题、提交记录、审查意见
- **价值**：与外部开发系统保持同步

## 信任分层机制

### 四级信任体系

| 级别 | 名称 | 特征 | 类比 |
|------|------|------|------|
| L1 | 工作记忆 | 私有草稿区，自由实验 | 本地分支 |
| L2 | 共享工作记忆 | 团队暂存区，可见未定稿 | 拉取请求 |
| L3 | 长期记忆 | 永久发布，带密码学证明 | 合并到主分支 |
| L4 | 已验证记忆 | 多方共识验证 | 正式发布版本 |

**应用价值**：智能体可按信任级别精确筛选信息，确保决策可靠性。
