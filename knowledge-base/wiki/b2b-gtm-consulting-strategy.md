## 核心概念解析

### B2B GTM咨询三维度模型（B2BFusion框架）

**Scope Shapes (范围形状)**：
```
Assessment (评估) ←→ Diagnostic (诊断)
├─ 周期: 2-6周
├─ 目标: 准备度图片+90天计划
└─ 价格: $25K - $60K

Workflow Redesign (工作流重设计) ←→ Implementation (实施)
├─ 周期: 6-12周  
├─ 目标: 端到端GTM运动重建
└─ 价格: $60K起 - $150K

Operating Partnership (运营合作) ←→ Ongoing Optimization (持续优化)
├─ 形式: 月度retainer
├─ 目标: 持续重设计+测量
└─ 价格: $15K - $40K/月
```

### 价格变异驱动因素分析

**数据状态 vs 高管对齐 vs 运动数量**
```
技术复杂度 ←→ 组织变革难度 ←→ 项目规模
├─ 数据清理成本 ←→ 变更管理成本 ←→ 并行工作成本
└─ 可预测性低 ←→ 成功关键 ←→ ROI稀释风险
```

## 与现有咨询服务的关联

### B2B GTM vs 企业级AI咨询

**客户细分对比**：
```
B2B GTM咨询 ←→ 企业级AI咨询
├─ 销售团队 ←→ CIO/CTO
├─ GTM运动 ←→ Agentic系统
├－ 回复率指标 ←→ ROI共享模型
└─ 快速见效 ←→ 长期价值
```

**定价策略差异**：
```
B2B GTM: 明确ROI计算 + 具体指标追踪
企业级: Token经济学 + ModelOps + 系统工程
```

### 增长引擎整合

**Perplexity五大引擎 ←→ B2B GTM咨询**：
```
有机增长 ←→ Assessment诊断
├─ 自然流量获取 ←→ 准备度评估
└─ 品牌认知建立 ←→ 90天计划

付费增长 ←→ Workflow redesign  
├─ ROI最大化 ←→ 具体指标提升
└─ 客户生命周期价值 ←→ 转换率优化

合作伙伴增长 ←→ Operating partnership
├─ 生态构建 ←→ 持续运营合作
└─ 价值共创 ←→ 月度retainer
```
