## 核心框架

### Agent外壳架构的"锁定效应"模型
```
外壳即记忆: 记忆不是插件，而是外壳的核心职责
锁定效应: 记忆制造锁定效应，是平台方的护城河
三个等级: 轻度(状态在服务器)、中度(记忆格式未知)、最坏(零可见零控制)

开放解法: 
- 开源: 外壳管理记忆代码可读，没有黑盒
- 模型无关: 可更换模型，记忆不丢失
- 开放标准: 采用agents.md、skills等标准格式
- 存储自选: 自选数据库，不被锁定
- 可自部署: 不依赖平台托管
```

### Agent架构成熟度模型
```
Level 1: 基础Agent → 简单RAG检索链，无记忆管理
Level 2: 有状态Agent → 有状态API，状态在平台服务器
Level 3: 封闭外壳Agent → 封闭外壳，记忆格式未知
Level 4: 开放外壳Agent → 开源外壳，模型无关，存储自选
Level 5: 自主Agent → 完全自主架构，记忆主权完整
```

## 核心认知

### 对行业的意义
1. **锁定效应**: Agent外壳与记忆紧密耦合，封闭外壳会导致记忆锁定
2. **数据主权**: 记忆是Agent时代的核心资产，需要保护主权
3. **开放标准**: 开放外壳、模型无关、存储自选为避免锁定的关键
4. **竞争优势**: 记忆是差异化体验的真正来源和竞争壁垒
