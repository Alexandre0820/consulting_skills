# Wiki知识整理指南 - AI咨询第二大脑构建

## 基于AI管理文章的整理策略

### 1. 三层架构实施建议

#### RAW层（原始输入）
**文件命名规范**：
- `[来源]_[主题]_[日期].md`（如：`wechat_ai_management_20260407.md`）
- 保留原始链接和抓取时间
- 不进行任何编辑，保持原貌

**分类原则**：
- 按来源分类：微信文章、LinkedIn、研究报告、客户文档
- 按主题标签：AI管理、组织设计、知识管理、商业模式

#### WIKI层（知识关联）
**框架设计原则**：

1. **主题聚合** - 将分散的知识点整合成框架
   ```
   示例：将31个Agent管理的多个要点 → "AI管理框架"
   ```

2. **概念关联** - 建立跨领域连接
   ```
   示例：Harness Engineering ↔ 传统管理学 ↔ 咨询方法论
   ```

3. **层级结构** - 从宏观到微观
   ```
   AI咨询方法论 → 数字组织设计 → 信息管理 → 具体工具
   ```

**标准模板**：
```markdown
## 核心理论框架
## 实践应用框架  
## 与咨询业务的关联性
## 关键案例参考
## 行动建议
```

#### OUTPUTS层（价值提炼）
**输出类型**：
1. **方法论指南** - 可直接使用的框架和工具
2. **案例分析** - 成功/失败的经验总结
3. **商业洞察** - 行业趋势和机会识别
4. **内容素材** - 文章、演讲、培训材料
