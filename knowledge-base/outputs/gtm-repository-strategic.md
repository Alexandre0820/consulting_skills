## 🧠 **核心模型**

**结构化markdown知识库** + **Claude Code** = **GTM智能大脑**

**价值**: 团队GTM能力沉淀为机器可执行的系统，每次会话自动加载上下文，任务变为单行prompt

**架构**: 5层（CLAUDE.md → Context Files → Skills → Workflows → Outputs）

---

## 💼 **AI咨询应用**

### 构建AI咨询Repository

**目录结构**:
- `CLAUDE.md`: 方法摘要+客户+优先级
- `context/methodologies/`: 定价框架/GTM策略/组织转型
- `context/case-studies/`: 案例库（成功/失败/进行中）
- `skills/`: 诊断技能（定价/GTM/组织）
- `workflows/`: 咨询项目全流程
- `outputs/`: 客户报告存档

### 半自动化交付

**传统**: 4周100%人工 → 成本高、不一致
**Repository+Claude**: 1周50%自动生成 → 成本降70%、一致性高

**流程**:
1. 客户输入基础信息
2. Claude Code读取Repository，调用相应skills
3. 生成报告初稿（50-70%完成度）
4. 人类顾问审核、调整、交付

---

## 🎯 **实施步骤**

1. **搭建Repository**: 建立CLAUDE.md + Context Files（2周）
2. **开发Skills**: 3个核心skills（定价诊断/GTM评估/组织转型）（3周）
3. **自动化测试**: 用历史项目测试，优化（2周）
4. **上线**: 用于新客户项目，监控质量（持续）
5. **迭代**: 每个项目后提炼，更新Repository（持续）
