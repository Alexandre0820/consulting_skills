## 核心框架

### Agentic Marketing Stack的"四工具链"模型
```
Idea Browser → 上下文与验证 → 通过MCP桥接Claude Code
Paper → 设计迭代 → 先在设计界面迭代视觉方向
Claude Code → 构建层 → 读取设计后直接生成生产代码
Humblytics → 分析与A/B测试 → 开箱即用的全漏斗追踪

闭环飞轮: 
Idea Browser → Paper → Claude Code → Humblytics → 结果回流Idea Browser → 下一次campaign
```

### Agentic Marketing成熟度模型
```
Level 1: 手动营销 → 手工创建内容，无设计迭代，无A/B测试
Level 2: Vibe-Coded营销 → 用AI工具但零上下文、零设计、零验证
Level 3: Agentic Stack营销 → 完整工具链，上下文优先，设计迭代，实时验证
Level 4: 智能化营销 → AI自动生成实验，自我优化，预测性分析
```
