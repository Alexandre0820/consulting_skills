## 二、方法论提炼

### 2.1 六条核心框架

**1. 职业转型准备框架**：
- 财务：2年无收入储备
- 心理：接纳零收入常态
- 触发：ChatGPT = 临界点

**2. 底层认知复利公式**：
- 经典论文(1956起) + 费曼学习法 + 10万字写作门槛
- → 认知复利 > 工资

**3. 企业孵化四大失败教训**：
- Top-down强推 → 政治成本极高
- 中间层 → 被底层协议进化淹没
- 微调小模型 → 泛化能力不如大模型
- 成熟拥挤赛道 → 新玩家极难突围

**4. 势能差理论**：
```
商业成功 = f(产品价值, 势能位置)
找到"缺水"位置 → 价值放大N倍
```

**5. 下沉末梢框架**：
- 不挑战AI上限 → 解决"脏活累活"
- 假牙OCR/打印店桌签 = 效率真空

**6. "真正的发布"**：
- 发布 = 定价 + 收钱
- 用户掏钱 = 真正的市场验证

## 三、补充理解：语核×句子互动会议核心观点

### 3.1 企业AI转型：Top-down vs Bottom-up

**池光耀观点**：大公司AI转型Top-down强推 → 沟通/政治成本极高
**李佳芮观点**：软件成本低，可快速帮传统公司数字化转型

**卡点分层**：
1. 数据就绪度（纸质/无资料/未构建系统）
2. 决策团队对AI转型的决心
3. 公司业务增量是否持续增长

### 3.2 鲁棒性四维度（更精细化）

| 维度 | 定义 | 解决方向 |
|------|------|---------|
| **意图鲁棒性** | 判断客户真实意图 | 模型能力增强可覆盖 |
| **工具鲁棒性** | 工具调用失败/重试/降级 | 工具接口质量 |
| **长城鲁棒性** | 跨小时/跨天持续执行 | 长时间稳定性 |
| **边界鲁棒性** | 识别能力边界，何时转人工 | 人和agent协作 |

### 3.3 创业护城河：双派系共识

**池光耀**：数据壁垒 + 工作流嵌入 = 替换成本
**李佳芮**：创新迭代速度 + 组织形态 = 核心护城河

**共识**：先发优势 + 客户数据积累 = 大厂无法替代

### 3.4 ROI证明方法论

**在线教育场景**：
- 对比AI组 vs 对照组接量转化
- 测试周期：8个月 → 2-6个月
- 大客户测试周期 ≥ 2个月

**通用框架**：无需精确计算，只需证明比同类产品有更高价值

### 3.5 首单客户获取

**渠道**：创始人关系 > 合伙人关系 > 口碑转介绍
**关键动作**：找到客户核心业务阻塞点 → 依赖agent能力拉取关键上下文

### 3.6 创业支点选择

**原则**：从熟悉、离钱近、客户付费意愿高的角度切入
**最优领域**：销售营销（易出结果、易量化）
