Ramp 的 AI 工具采用率达到了 99%，然后他们发现了一个令人担忧的问题：大多数人卡住了。

不是因为模型不够好，也不是因为员工不够聪明或缺乏雄心。只是终端窗口、npm 安装、MCP 配置——对大多数人来说实在太难了。少数坚持下来的人建起了千差万别的环境，却没有办法把自己学到的东西分享给别人。公司制造了紧迫感，却没有提供足够的基础设施，把 AI 真正的潜力限制在了那些本来就懂得如何配置的人身上。

于是他们决定自己动手，打造了一套内部 AI 生产力工具，叫做 Glass。

Glass 上线仅 1 个月：700 日活用户，350+ 共享技能
01 三个原则
:::

构建 Glass 之前，Ramp 团队围绕三个核心原则达成了共识。

Seb Goddijn 有一个比喻：大多数人使用 AI 就像开着一辆法拉利却拉着手刹。不是因为他们不聪明，也不是因为缺乏雄心，只是他们从来没有见过一个配置完善的环境是什么样子，也不知道它能做什么。

Glass 的目标是松开这个手刹——对所有人，不只是那些愿意花时间折腾 npm 和 MCP 配置的工程师。

第一，不降低任何人的天花板。 面向非技术用户，但不会降低技术用户的上限。Glass 的设计目标是让所有员工都能轻松使用 AI，同时不限制技术用户的高级功能需求。

第二，建立统一的基础设施。 不再让每个员工各自为政地配置自己的 AI 环境，而是建立一套统一的基础设施，让所有人都能在同一个平台上协作和分享。

第三，降低采用门槛。 通过简化配置流程，让员工能够快速上手，不需要深入了解技术细节。

02 Glass的核心功能
:::

1. 技能共享系统
:::

这是 Glass 最核心的功能。员工可以创建自己的 AI 技能（如代码生成、数据分析、文档处理等），然后分享给整个团队使用。

技能创建过程非常简单：
- 选择技能类型（如代码助手、数据分析、内容生成等）
- 配置技能参数（如模型选择、提示词模板等）
- 测试技能效果
- 发布到技能库

其他员工可以：
- 浏览技能库，找到需要的技能
- 一键使用该技能
- 对技能进行评价和反馈
- 基于现有技能创建改进版本

这种技能共享模式解决了两个核心问题：
- 知识孤岛：少数人掌握的技能可以惠及整个团队
- 重复造轮子：避免不同员工重复开发相似功能

2. 统一配置管理
:::

Glass 提供了统一的配置管理界面，员工不需要手动配置：
- MCP 服务器配置
- API 密钥管理
- 模型参数设置
- 环境变量管理

所有配置都在云端统一管理，员工只需要登录 Glass 平台即可使用。

3. 协作功能
:::

- 技能版本控制：记录技能的迭代历史
- 协作编辑：多人可以同时编辑和优化技能
- 使用统计：追踪技能的使用情况和效果
- 反馈机制：用户可以提供反馈，帮助改进技能

4. 安全与合规
:::

- 数据隔离：确保不同团队的数据相互隔离
- 访问控制：基于角色的访问权限管理
- 审计日志：记录所有 AI 操作，便于合规审查
- 数据加密：保护敏感数据的安全

03 实施效果
:::

上线仅 1 个月，Glass 取得了显著效果：

- 700 日活用户：几乎覆盖了 Ramp 的所有员工
- 350+ 共享技能：员工创建了丰富的技能库
- 99% 采用率：几乎所有员工都在使用 Glass
- 生产力提升：员工反馈工作效率显著提升

04 关键成功因素
:::

1. 高层支持
:::

- 管理层认识到 AI 的重要性
- 投入足够的资源进行开发
- 推动全公司范围内的采用

2. 用户导向设计
:::

- 简化用户体验，降低使用门槛
- 提供丰富的技能模板
- 建立反馈机制，持续改进

3. 持续迭代
:::

- 基于用户反馈快速迭代
- 定期添加新功能
- 优化性能和稳定性

4. 文化建设
:::

- 鼓励员工分享技能
- 建立最佳实践
- 组织培训和交流活动

05 对其他企业的启示
:::

1. 自建 vs 采购的决策框架
:::

Ramp 的经验表明，对于 AI 生产力工具，自建可能是更好的选择，原因如下：

- 定制化需求：商业工具往往无法满足企业的特定需求
- 数据安全：自建可以更好地控制数据安全
- 成本效益：长期来看，自建可能更具成本效益
- 竞争优势：自建的 AI 能力可以成为企业的竞争优势

2. 降低采用门槛是关键
:::

- 技术门槛：大多数员工不具备配置 AI 环境的能力
- 学习成本：需要提供简单易用的界面和培训
- 时间成本：员工需要时间来适应新的工作方式

3. 建立共享文化
:::

- 知识共享：鼓励员工分享自己的技能和经验
- 协作文化：建立团队协作和知识传递的文化
- 持续学习：营造持续学习和改进的氛围

06 总结
:::

Ramp 的 Glass 项目展示了企业自建 AI 生产力工具的巨大潜力。通过降低采用门槛、建立统一基础设施、促进技能共享，企业可以充分发挥 AI 的潜力，提升整体生产力。

对于咨询公司来说，Ramp 的经验具有重要的借鉴意义。咨询公司可以考虑建立自己的 AI 生产力平台，以提升服务效率和质量，同时保持竞争优势。
